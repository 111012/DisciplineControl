# 平板安装与使用说明

> 适配：小米平板 5 / 6 均可；Android 11–13（实测小米平板 6、Android 13、MIUI V140）。
> 安装包：`dist/DisciplineControl-v0.2.0-release.apk`（日常用，推荐）或 `dist/DisciplineControl-v0.2.0-debug.apk`（调试用，带 adb 调试广播）。当前 v0.2.0 / versionCode 10，两者同签名可互相覆盖安装。

---

## 第一步：装 APK

三种方式任选：

1. **数据线**：把 `dist\DisciplineControl-v0.2.0-release.apk` 拷到平板任意目录，用平板的"文件管理"点开安装。
2. **微信/QQ 传文件**：发给自己，在平板上保存后在文件管理里安装。
3. **adb**（如果平板开了 USB 调试）：
   ```powershell
   .\.toolchain\android-sdk\platform-tools\adb.exe install -r -g dist\DisciplineControl-v0.2.0-release.apk
   ```

安装时系统会提示"来自未知来源"，选**允许**。

> 如果之前装过旧版本，直接覆盖安装即可（签名固定）。卸载会丢规则，但**不会**把平板锁死——这不是设备管理员应用。

---

## 第二步：第一次打开（设 PIN）

1. 打开「自律控制」。
2. 点右上角齿轮 → 首次会让你设 PIN（4–8 位数字）。**记住它，忘了只能清除数据重来。**
   > 测试期这台机器上设的是 `1234`，自己用请改掉（设置 → 修改 PIN）。
3. 进入设置页，从上往下按 ①–⑤ 全部处理掉。

---

## 第三步：四项必须给的权限

### ① 默认桌面（让图标能真正隐藏）

设置 → 权限与开关 → **① 默认桌面** → 去设置 → 在"默认桌面/主屏幕应用"里选 **自律控制** → 选"始终"。

> 换回原来的桌面：设置 → 应用 → 默认应用 → 主屏幕应用 → 选回小米桌面。
> 换了桌面之后，按 Home 键、上滑回桌面，都会回到「自律控制」的桌面。

### ② 无障碍服务（拦截启动的唯一手段）

设置 → 权限与开关 → **② 无障碍服务** → 去开启 → 系统设置里找到「自律控制 · 应用守护」→ 打开 → 确认。

> 只读取"当前前台应用的包名"（用于主动查询焦点窗口），不采集屏幕内容、不联网。系统会在通知栏常驻一条无障碍提示，正常现象。
> 它被系统关掉时，App 会在 15 秒内发「拦截已失效」通知，点通知进**一键修复页**（`RepairActivity`，不需要 PIN）；桌面顶部也会显示「⚠ 守护未运行：点此修复」。

### ③ 通知权限（到点提醒）

Android 13 首次启动会弹通知权限，选**允许**；没弹的到：设置 → 权限与开关 → **③ 通知权限** → 去允许。

### ④ 悬浮窗（可选）

只有你想开"游戏内悬浮横幅"时才需要。默认关闭，建议先不开（见下方风险说明）。

---

## 第四步：MIUI 后台设置（非常关键）

小米系统会杀后台，不做这三步计时会中断：

1. **自启动**：设置 → 应用设置 → 应用管理 → 自律控制 → **自启动** → 允许
2. **省电策略**：同上页面 → **省电策略** → 无限制
3. **锁定后台**：打开最近任务（多任务键/上滑悬停）→ 找到自律控制卡片 → **下拉锁定**（出现小锁）

设置页里的 **⑤ 后台与自启动** 会显示电池优化是否已忽略，点"去设置"可以快速跳转。

---

## 升级后必做：复查默认桌面

MIUI 在**覆盖安装**（`adb install -r` 或直接装新 APK）后，会把默认桌面重置回「小米桌面」。这时 App 还在、规则也还在，但图标隐身会失效——小米桌面上仍能看到王者图标。

升级后按任一方式重设：

1. 设置 → 应用 → 默认应用 → 主屏幕应用 → **自律控制**。
2. 或 adb（项目内 adb 在 `.toolchain\android-sdk\platform-tools\adb.exe`）：
   ```powershell
   adb shell cmd package set-home-activity com.discipline.control/.ui.HomeActivity
   ```
3. 或直接重跑 `pwsh -File scripts/adb-deploy.ps1`（会顺带重新授权、开无障碍）。

复查：

```powershell
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

输出应为 `com.discipline.control/.ui.HomeActivity`；再回桌面确认时段外的受控应用不在图标列表里。

---

## 第五步：添加要管控的应用（比如王者荣耀）

1. 桌面 → 右上角齿轮（输 PIN）→ 管控应用 → **＋ 添加管控应用**
2. 在列表里找到 **王者荣耀** → 点它
3. 会自动套用默认规则：`每天 20:00–23:00 · 每日 3 次 · 单次 60 分钟 · 提醒后宽限 20 分钟`
4. 按需修改后点**保存**

### 每个参数的位置

| 想改什么 | 在哪改 |
|---|---|
| 哪个时间段能玩 | 规则页 → 开放时段 → 点时段修改 / ＋添加时段（可加多个，可跨零点） |
| 每天能开几次 | 规则页 → 每日最多打开次数（0 = 不限） |
| 一次能玩多久 | 规则页 → 单次使用时长（分钟） |
| 提醒后还能玩多久 | 规则页 → 提醒后宽限（分钟） |
| 切后台算不算新的一次 | 规则页 → 离开多久算新的一次（分钟） |
| 到 23:00 是否立刻踢 | 规则页 → 时段结束时立即退出 |
| 每天几点重置次数 | 设置 → 全局设置 → 每天几点重置次数 |
| 改规则要不要等 24 小时 | 设置 → 全局设置 → 放宽限制的修改需等待 |
| 到点怎么提醒 | 设置 → 全局设置 → 到点提醒方式（三档，现状见下表） |

> **"放宽"会延迟生效**：调大次数/时长、扩时段、开新时段这类修改会进入"待生效"，等 N 小时后自动生效（设置页能看到倒计时和取消按钮）。收窄限制（减次数、缩时段）立刻生效。

### 到点提醒方式三档现状

| 档位 | 行为 | 现状 |
|---|---|---|
| ① 仅通知 + 震动（默认） | 游戏内只收通知 + 震动，不覆盖画面 | ✅ 已实测（计时链路就是这一档） |
| ② 通知 + 游戏内悬浮横幅 | 额外用 `TYPE_APPLICATION_OVERLAY` 弹横幅 | 未实测；默认关闭，有被 ACE 误判的风险 |
| ③ 到点先退回桌面 | warn 后立即回桌面，桌面显示「⏳ 还剩 X 分钟」 | ✅ 已实测：60 秒 warn 后立刻回桌面，不覆盖游戏画面；点回续用与倒计时未实测 |

## 第六步：验证是否生效

| 场景 | 期望结果 |
|---|---|
| 白天打开桌面 | 王者荣耀图标**不在**桌面上 |
| 从最近任务点王者 | 立刻弹回桌面，通知栏提示"已被拦截 · 不在开放时段" |
| 20:00 之后回桌面 | 王者图标出现 |
| 打开王者 | 通知栏常驻"王者荣耀 使用中 · 剩余 60 分钟" |
| 连续打开 3 次（每次间隔超过 5 分钟） | 第 4 次点开直接被弹回，提示次数用完 |
| 用满 60 分钟 | 弹提醒"还有 20 分钟"，震动 |
| 用满 80 分钟 | 被强制退回桌面，今天桌面上不再出现王者 |
| 第二天 0 点后 | 次数、时长全部重置 |

## 排错

| 现象 | 原因 / 处理 |
|---|---|
| 王者图标一直都在 | 默认桌面没换成自律控制（设置里 ① 应为"已设为默认桌面"）；或规则里"启用管控"被关了 |
| 升级/覆盖安装后王者图标一直显示 | MIUI 把默认桌面重置回了小米桌面；按「升级后必做：复查默认桌面」重设 |
| 点王者能正常进，不被弹回 | 无障碍服务被系统关了（MIUI 偶发）：重开；或"电池优化"没忽略导致服务被杀 |
| 收到「拦截已失效」通知 | 无障碍被系统关掉了（手动关、或用了「强行停止」）。点通知进修复页 → 开启无障碍；桌面顶部也会出现「⚠ 守护未运行」 |
| 用「强行停止」/`am force-stop` 后不再拦截 | Android 行为：强停会把无障碍服务一起关掉（`enabled_accessibility_services` 被清空）。重新打开一次无障碍，或点「拦截已失效」通知一键修复 |
| 提醒没弹出来 | 通知权限没给；或 MIUI 的"通知管理"里把本应用通知关了 |
| 计时不准 / 中途归零 | 服务被杀。检查自启动、省电策略、后台锁定；重开 App 会自动重启服务 |
| 悬浮横幅不显示 | 没给悬浮窗权限；或「到点提醒方式」没选第二档 |
| PIN 忘了 | 在系统设置里清除本应用数据（会丢失全部规则和统计） |

---

## 风险提示

- 默认的「仅通知 + 震动」和「到点先退回桌面」都**不覆盖游戏画面**，不会触发反外挂误判。
- 只有第二种「通知 + 游戏内悬浮横幅」会用到 `TYPE_APPLICATION_OVERLAY`，理论上有被 ACE 判为辅助工具的风险，所以默认关闭；想要"砸脸"又怕风险，选第三种。
- 本应用**不是**设备管理员：任何时候都能被卸载，不会锁死平板。
- 无障碍服务可以被手动关闭，这是 Android 层面的限制，任何非 root 方案都一样。
- 系统「强行停止」或 `am force-stop` 会把无障碍服务一并关掉（Android 行为），拦截随即失效；用「拦截已失效」通知或重新打开无障碍恢复。
