## 五、真机暴露的两个坑

### 5.1 MIUI 插入 `com.miui.securitycenter` 窗口，计时卡死

**现象**

拉起王者时，MIUI 会在游戏之上插一个 `com.miui.securitycenter` 窗口，导致会话暂停。旧逻辑只监听 `TYPE_WINDOW_STATE_CHANGED`：

1. 收到 securitycenter 的前台事件 → 判定离开游戏 → `session pause`；
2. 游戏回到前台时**不再发** `TYPE_WINDOW_STATE_CHANGED`（或事件被吞）；
3. 会话一直停在暂停状态，计时卡死，永远到不了 warn / finish。

**根因**

- 只依赖窗口状态变化事件；
- 无障碍配置 `canRetrieveWindowContent=false`，无法主动查当前焦点窗口；
- 没有兜底轮询，焦点回切后没有第二次机会。

**修复**

| 项 | 修复前 | 修复后 |
|---|---|---|
| 事件来源 | 仅 `TYPE_WINDOW_STATE_CHANGED` | 增加 `TYPE_WINDOWS_CHANGED` |
| 兜底 | 无 | 每 2 秒主动查 `rootInActiveWindow` 包名 |
| 无障碍配置 | `canRetrieveWindowContent=false`、`flagDefault` | `true`、`flagRetrieveInteractiveWindows` |
| 去重 | 无 | `lastReconciledPkg`，同一包名不重复处理 |

实现位置：`GuardAccessibilityService.activePackage()` / `onAccessibilityEvent`，`GuardService.onTick()` 的 `tickCount % 2 == 0` 轮询。注意：没有把 `com.miui.securitycenter` 直接当作临时窗口忽略（单测明确断言它不是），而是用「焦点回切后主动查询」兜底，避免把真正的安全中心界面也当成游戏。

**修复后验证**

- MIUI 悬浮窗出现再消失后，会话继续，不再 `session pause` 卡死；
- 日志能看到 `poll -> com.tencent.tmgp.sgame`；
- 1+1 分钟链路正常走到 61 秒 warn、121 秒 finish。

### 5.2 覆盖安装（`adb install -r`）重置默认桌面

**现象**

`adb install -r` 升级后，按 Home 回到的是**小米桌面**；自律控制仍在、规则也在，但小米桌面照常显示王者图标 —— 图标隐身失效。

**原因**

MIUI 在覆盖安装后把「主屏幕应用」恢复成小米桌面，`set-home-activity` 的设置被清掉。

**处理**

1. 重新执行 `adb shell cmd package set-home-activity com.discipline.control/.ui.HomeActivity`；
2. 或重跑 `pwsh -File scripts/adb-deploy.ps1`（脚本每次都会重设默认桌面）；
3. 用 `adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME` 复查，输出应为 `com.discipline.control/.ui.HomeActivity`。

**影响**

只影响默认桌面，不影响规则、当日用量、PIN。**升级后必须重设一次**，否则隐身相关验收会全部误判为失败。

## 七、如何复跑

```powershell
# Windows PowerShell 5.1 需要；PowerShell 7（pwsh）可跳过
Set-ExecutionPolicy -Scope Process Bypass

# 装包 + 授权 + 设默认桌面 + 开无障碍 + 回显验证
pwsh -File scripts/adb-deploy.ps1

# 复查默认桌面（覆盖安装后必看）
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

冒烟脚本：

```powershell
pwsh -File scripts/adb-smoke.ps1 -Mode block    # 时段外拉起，验证 NOT_IN_WINDOW
pwsh -File scripts/adb-smoke.ps1 -Mode warn     # 脚本默认 2 分钟 + 宽限 1 分钟
pwsh -File scripts/adb-smoke.ps1 -Mode count    # 连续 4 次，第 4 次 NO_OPENS_LEFT
pwsh -File scripts/adb-smoke.ps1 -Mode status   # 规则 / 用量 / 待生效
pwsh -File scripts/adb-smoke.ps1 -Mode reset    # 清今日用量
```

复现本次 1+1 分钟计时（比脚本快）：

```powershell
adb shell am broadcast -a com.discipline.control.DEBUG -e cmd reset-day
adb shell am broadcast -a com.discipline.control.DEBUG -e cmd rule --es pkg com.tencent.tmgp.sgame `
    --ei startHour 0 --ei endHour 24 --ei opens 3 --ei sessionMin 1 --ei graceMin 1 --ei gapMin 0
adb shell monkey -p com.tencent.tmgp.sgame -c android.intent.category.LAUNCHER 1
# 第 61 秒 warn，第 121 秒 finish reason=DAY_FINISHED
```

次数限制不必真开 3 次：

```powershell
adb shell am broadcast -a com.discipline.control.DEBUG -e cmd set-usage --es pkg com.tencent.tmgp.sgame --ei opens 3
adb shell monkey -p com.tencent.tmgp.sgame -c android.intent.category.LAUNCHER 1
# block ... reason=NO_OPENS_LEFT
```

待生效链路：

```powershell
adb shell am broadcast -a com.discipline.control.DEBUG -e cmd pending-demo --es pkg com.tencent.tmgp.sgame
# 20 秒后自动生效，通知「设置已生效」；期间设置页可见「生效时间」+ 取消
```

看日志：

```powershell
pwsh -File scripts/adb-logs.ps1
# 或
adb logcat -s DC/Guard:V DC/A11y:V DC/Debug:V DC/Home:V
```

> `scripts/*.ps1` 已存为 UTF-8 BOM，兼容 Windows PowerShell 5.1；若仍报「无法加载文件，未对文件进行数字签名」，先执行上面的 `Set-ExecutionPolicy`。
