# 平板验收测试清单（v0.1.0）

装的包：`dist/DisciplineControl-v0.1.0-debug.apk`
建议先把「放宽限制的修改需等待」临时改成 **0 小时**，方便测试时快速改参数；测完再改回 24 小时。

> 测试中每一步如果和"期望"不一致，把 **现象 + 当时的时间 + 是不是从最近任务进去的** 记下来发我，我按现象改。

---

## A. 安装与权限

| # | 操作 | 期望 |
|---|---|---|
| A1 | 安装 APK | 安装成功，应用名「自律控制」 |
| A2 | 打开 App | 进入桌面页，能看到已安装应用网格；右上角齿轮可点 |
| A3 | 点齿轮 | 首次弹"设置 PIN"；设完进设置页 |
| A4 | 设置 ① 默认桌面 → 选自律控制 | 按 Home 键回到本应用桌面；设置里 ① 变成"已设为默认桌面" |
| A5 | 设置 ② 无障碍 → 打开「自律控制 · 应用守护」 | 通知栏出现无障碍提示；桌面顶部红色提示消失 |
| A6 | 允许通知 | 桌面顶部"③ 允许通知"提示消失 |
| A7 | 关电池优化 + MIUI 允许自启动 + 锁定后台 | 设置 ⑤ 显示"已忽略电池优化" |
| A8 | 下拉通知栏 | 有常驻通知"自律控制 · 守护中 · 已管控 0 个应用" |

## B. 添加与管理规则

| # | 操作 | 期望 |
|---|---|---|
| B1 | 设置 → 添加管控应用 → 王者荣耀 | 添加成功并进入规则页，默认值：每天 20:00–23:00 / 3 次 / 60 分钟 / 宽限 20 分钟 / 计数间隔 5 分钟 |
| B2 | 返回桌面 | 只要当前**不在 20:00–23:00**，王者荣耀图标不在桌面上 |
| B3 | 设置页看管控列表 | 显示"王者荣耀 · 每天 20:00–23:00 · 每日 3 次 · 单次 60 分钟（+20 分钟宽限）" |
| B4 | 规则页把时段改成"现在这个时间" | 保存成功（收紧不用等），回桌面图标出现 |

## C. 隐身 / 拦截

| # | 操作 | 期望 |
|---|---|---|
| C1 | （时段外）打开最近任务，点王者荣耀 | 立刻回到本应用桌面；通知栏提示"王者荣耀 已被拦截 · 不在开放时段，下次开放：今天 20:00"；桌面上没有它的图标 |
| C2 | （时段外）在设置 → 应用 → 王者荣耀 → 打开 | 同样被弹回桌面 |
| C3 | （时段外）用微信/QQ 里的游戏入口打开王者 | 同样被弹回桌面 |
| C4 | （时段内）桌面点王者 | 正常进入游戏 |
| C5 | 在游戏里按 Home，再点桌面王者 | 正常进入，**不算新的一次**（离开不足 5 分钟） |
| C6 | 在游戏里按 Home，等 6 分钟，再点桌面王者 | 正常进入，这次**算新的一次**（看统计或状态行次数 +1） |

## D. 次数限制

| # | 操作 | 期望 |
|---|---|---|
| D1 | 每次间隔 6 分钟以上，打开王者 3 次 | 第 1、2、3 次都能进；桌面状态行显示"今日已用 3/3 次"；之后图标从桌面消失 |
| D2 | 第 4 次尝试（最近任务/应用信息/桌面已无图标，用最近任务试） | 被弹回桌面，提示"今天的 3 次已经用完了，明天 0 点之后再来" |

## E. 时长提醒 / 强制退出

建议把「单次使用时长」临时改成 **2 分钟**、「提醒后宽限」改成 **1 分钟** 来测，测完改回 60 / 20。

| # | 操作 | 期望 |
|---|---|---|
| E1 | 进王者，等满 2 分钟 | 收到提醒通知"已使用 2 分钟，1 分钟后将强制退出"+ 震动；常驻通知显示剩余分钟在减少 |
| E2 | 继续等到 3 分钟 | 被强制退回桌面；通知"王者荣耀 已强制退出 · 今天的时间/次数已经用完"；桌面图标消失 |
| E3 | 当天再尝试打开 | 一律被拦，提示今日已用完 |
| E4 | 重新进设置把规则时长调小 | 收紧立即生效，不弹等待提示 |
