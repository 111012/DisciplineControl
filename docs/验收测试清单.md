## 真机自动化验证（adb）

前置：debug 包已装、平板已开 USB 调试且授权、`adb devices` 能看到设备。

```powershell
Set-ExecutionPolicy -Scope Process Bypass   # 仅 Windows PowerShell 5.1 需要；pwsh 7 可跳过
pwsh -File scripts/adb-deploy.ps1           # 装最新 dist/*.apk + 授权 + 设默认桌面 + 开无障碍
```

| 目的 | 命令 |
|---|---|
| 只重授权、不重装 | `pwsh -File scripts/adb-deploy.ps1 -SkipInstall` |
| 实时判定日志 | `pwsh -File scripts/adb-logs.ps1` |
| 截屏到 `screenshots/` | `pwsh -File scripts/adb-shot.ps1 -Name home` |
| 时段外拦截 | `pwsh -File scripts/adb-smoke.ps1 -Mode block` |
| 提醒 → 强制退出 | `pwsh -File scripts/adb-smoke.ps1 -Mode warn` |
| 次数限制 | `pwsh -File scripts/adb-smoke.ps1 -Mode count` |
| 当前规则 / 用量 / 待生效 | `pwsh -File scripts/adb-smoke.ps1 -Mode status` |
| 清今日用量 | `pwsh -File scripts/adb-smoke.ps1 -Mode reset` |

判定标准：

- `block`：4 秒后前台不是王者，日志有 `block ... reason=NOT_IN_WINDOW`。
- `warn`：先 `warn ...`，再 `finish ... reason=DAY_FINISHED`，最后 `block ... forced=true`。
- `count`：前 3 次 `session start`，第 4 次 `block ... reason=NO_OPENS_LEFT`。
- 日志 tag：`DC/Guard`（判定/计时）、`DC/A11y`（窗口事件）、`DC/Debug`（广播）、`DC/Home`（桌面）。

调试广播 `status / reset-day / rule / set-usage / config / pending-demo / remove / clear` 的用法见 README「六、真机调试（adb）」；全部只在 debug 包生效。

> 覆盖安装后 MIUI 会把默认桌面重置回小米桌面。先重跑 `adb-deploy.ps1` 再测，否则「图标隐身」会误判为失败。
